## 2. Обзор Панели (Dashboard)

При входе вы попадаете на главную панель (Dashboard), где отображается статистика системы:
*   **Total Users (Всего пользователей):** Общее количество зарегистрированных пользователей.
*   **Total Transactions (Всего транзакций):** Общее количество операций в системе.
*   **System Volume (Объем системы):** Сумма всех транзакций в долларовом эквиваленте (USD).

## 3. Управление Пользователями (Users)

Раздел "Users" позволяет полностью управлять базой пользователей.

### Функции:
*   **Поиск:** Используйте поле поиска вверху для фильтрации пользователей по Email или ID.
*   **Список:** Таблица отображает Email, Имя, Страну, Телефон и Баланс USDT.
*   **Редактирование (Edit):** Нажмите кнопку ✏️ (Info), чтобы изменить данные пользователя:
    *   Личные данные (Имя, Страна, Телефон).
    *   **Баланс Кошельков:** Вы можете вручную изменить баланс любой валюты (USDT, BTC, ETH и др.) для пользователя.
    *   *Примечание:* Все изменения баланса логируются в транзакциях как `Replenished` (Пополнение админом).
*   **История (History):** Нажмите кнопку 🕒 (Warning), чтобы посмотреть полную историю транзакций конкретного пользователя.
*   **Удаление (Delete):** Нажмите кнопку 🗑️ (Danger), чтобы безвозвратно удалить пользователя и его данные. **Будьте осторожны!**

---

## 4. Управление Валютами (Coins)

Раздел "Coins" позволяет управлять торговыми парами, доступными на платформе.

*   **Добавить валюту:** Введите символ (например, `DOGE`, `LTC`) в поле "Symbol" и нажмите "ADD". Новая пара будет мгновенно доступна для торгов.
*   **Удалить валюту:** Нажмите на крестик ❌ рядом с названием валюты в списке "Active Market Pairs".

---

## 5. Транзакции (Transactions)

Раздел "Transactions" предоставляет глобальный журнал всех операций в системе.

### Фильтры:
*   **Type (Тип):** Buy (Покупка), Sell (Продажа), Deposit (Депозит), Withdraw (Вывод), Replenished (Админ).
*   **Asset (Актив):** Фильтр по конкретной валюте (например, BTC).
*   **User (Пользователь):** Поиск транзакций конкретного пользователя по Email или ID.
*   **Limit (Лимит):** Количество отображаемых записей (50, 100, 200, 500).

Используйте кнопку **Refresh**, чтобы обновить список с учетом фильтров.

---

## 6. Чат Поддержки (Chats)

Раздел "Chats" позволяет общаться с пользователями в режиме реального времени.

*   **Список чатов:** Слева отображается список пользователей, написавших в поддержку.
    *   🔴 Красный индикатор с числом показывает количество непрочитанных сообщений.
    *   Индикатор статуса (зеленый/серый) показывает активность чата.
*   **Окно диалога:** Выберите пользователя из списка, чтобы открыть переписку.
*   **Отправка сообщений:** Введите текст в поле ввода и нажмите кнопку отправки. Сообщение мгновенно появится у пользователя.
